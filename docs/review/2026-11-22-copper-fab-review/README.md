## Method

One reviewer, no sub-agents, **cold**: no prior `docs/review/` directory and no
other thread's notes were read. The hand-routing rules (ADR 0030) were read for
what the boards intend.

Geometry was taken straight from each board with KiCad 9.0.9's `pcbnew` and
turned into polygons (`tools/geo.py` here): every track, via, pad on every
copper layer, zone fill, mask opening, silkscreen item, hole and the outline.
The checks in `tools/c1.py`–`c5.py` then measure distances on those polygons.
KiCad's own DRC was run once as a baseline; it is clean on all five under the
boards' own rules (0 violations, 0 unconnected), which is why nothing below is
a rule the boards already hold themselves to.

Provenance marks: `[test]` a measurement by the scripts here, `[ds]` the banked
capability page, `[calc]` arithmetic shown, `[repo]` a file in this repository,
`[from memory]` unverified.
